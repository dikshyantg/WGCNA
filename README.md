# WGCNA preprocessing workflow

This repository contains an R script for cleaning an expression matrix and running a baseline **WGCNA** module discovery workflow.

## Files

- `Data_preprocessing_apr29.R`: End-to-end preprocessing + WGCNA analysis script.
- `README.md`: Usage and outputs.

## What the script does

1. Loads a gene expression matrix from CSV.
2. Keeps numeric columns and removes rows with missing values.
3. Transposes data to the WGCNA-required shape (samples as rows, genes as columns).
4. Estimates a soft-thresholding power with `pickSoftThreshold`.
5. Runs `blockwiseModules` to identify co-expression modules.
6. Writes module assignments and diagnostic plots.

## Requirements

Install required R packages:

```r
install.packages(c("WGCNA", "data.table", "dplyr", "reshape2", "tidyr", "ggplot2"))
```

## Input format

Input CSV should have:

- **Rows**: genes
- **Columns**: samples
- **First column**: gene identifier used as row names
- Numeric expression values in the matrix

## Usage

```bash
Rscript Data_preprocessing_apr29.R <input_csv> [output_dir]
```

Example:

```bash
Rscript Data_preprocessing_apr29.R data/merged_final_pre_gene_network.csv results
```

If `output_dir` is omitted, outputs are written to `./output`.

## Outputs

- `soft_threshold_diagnostics.png`: scale-independence and connectivity diagnostic plots.
- `gene_modules.csv`: table mapping each gene to its assigned module color.
- `module_eigengene_heatmap.png`: sample-by-module eigengene heatmap.
- `TOM-block.*`: TOM files generated by WGCNA when `saveTOMs=TRUE`.

## Notes

- If `pickSoftThreshold` cannot estimate a power, the script falls back to `16`.
- The script performs a minimal quality check and stops if the matrix is too small for reliable WGCNA.
